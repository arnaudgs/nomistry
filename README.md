# Nomistry

Idée d'application : un générateur de noms de projet ou de marque. L'utilisateur décrit son projet, choisit la longueur, le style et le thème, puis l'IA propose des noms dont l'application vérifie la disponibilité (noms de domaine, marques déposées…).

Le dépôt ne contient pas de code. `APP_PROMPT.md` est le cahier des charges destiné à générer l'application (React, Next.js).
